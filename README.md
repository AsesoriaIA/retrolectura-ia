# RetroLectura IA

Prototipo funcional construido para la actividad **Del concepto a la práctica** (Semana 4) del curso *Inteligencia Artificial para la Docencia* — Maestría en Educación Mediada por las TIC, Universidad Tecnológica de Bolívar.

**Grupo 01:** Maritza Jiménez Saldarriaga · Betty Esperanza Lagos Quintero · Yessica Márquez Núñez
**Docente:** María Cecilia Aroca Díaz

## Qué es
Prototipo web que digitaliza las respuestas manuscritas de un control de lectura, genera observaciones específicas por estudiante con base en la rúbrica del curso y produce un reporte consolidado por criterio de comprensión (idea principal, inferencia, argumentación). La IA hace la primera revisión; el docente valida antes de comunicar.

## Cómo probarlo
Abrir `index.html` (o el sitio publicado) y usar el botón **Cargar demostración completa** para ver el flujo con ocho respuestas de ejemplo. El recorrido está organizado en tres roles: docente, estudiante y sistema.
